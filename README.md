# 3Kings - Three Kingdoms

Japanese version: [README_ja.md](README_ja.md)

## About

`3Kings - Three Kingdoms` is a tactical simulation war game for MSX.

Choose a scenario and ruler, expand your territory through strategy and tactical battles,
and aim to unite all 14 provinces.

## System Requirements

- MSX1 / MSX2 compatible environment
- MSX2 or later recommended
- 64KB RAM or more
- PSG sound
- 2Mbit ROM cartridge
- Konami MegaROM compatible environment
