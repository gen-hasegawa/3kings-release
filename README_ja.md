# 3Kings - Three Kingdoms

English version: [README.md](README.md)

## 概要

`3Kings - Three Kingdoms` は、MSX 向けの戦術級シミュレーション・ウォーゲームです。

シナリオと君主を選び、政略と戦術戦闘を通じて勢力を広げ、
全国 `14` 州の統一を目指します。

## 動作環境

- MSX1 / MSX2 互換環境
- MSX2 以上を推奨
- RAM `64KB` 以上
- PSG 音源
- `2Mbit` ROM カートリッジ
- Konami MegaROM 互換環境
